# Project Starter

Create a new, consistently named project folder from a template, in one click. Works on Windows and macOS (and Linux).

Type a name, pick where it goes, press **Enter**. You get `26-12-My Project` (year, next project number, name) with your folder structure inside, ready in Explorer/Finder.

## Features

- **Templates:** Motion/Video (default), Photo, Graphic Design, 3D, Web/Dev and Music, or point to **any folder** on disk and use its structure (files included).
- **Template editor:** add, rename, delete and reorder folders; rename and duplicate templates. Presets stay intact: editing one creates your own copy.
- **Dark mode** by default (light mode in Settings → General), Kal-Motion blue, rounded buttons.
- **Naming you control:** build the folder name from tokens, with a live preview. Built-in schemes plus your own.
- **Live preview** of the folder name and the full folder tree before anything is created.
- **Safe:** invalid characters are cleaned, existing folders are never overwritten, long-path warnings, and failed creations are rolled back.
- **Undo last** (Ctrl+Z, or *Settings → General*): removes the last project, but only while it is still untouched.
- **Right-click "New project here"** in Explorer and Finder.
- Remembers your last destination (with a list of recent ones), template and naming scheme.
- Keyboard: **Enter** create · **Esc** close · **Ctrl+Z** undo last · **Ctrl+E** edit template · **Ctrl+O** browse · **Ctrl+,** settings.

## Run from source

Needs Python 3.9+ with Tkinter (included with the python.org installers; on Debian/Ubuntu: `sudo apt install python3-tk`).

```
python run.py
python run.py --dest "D:\Projects\26 Projects" --name "Brand Film"
```

No third-party packages are needed to run it.

## Naming

A pattern is text with tokens. The default is `{YY}{sep}{NN}{sep}{name}` → `26-12-My Project`.

| Token | Meaning |
|---|---|
| `{YYYY}` `{YY}` | year, 4 or 2 digits |
| `{MM}` `{DD}` | month, day |
| `{NN}` | project counter |
| `{name}` | what you typed (required, exactly once) |
| `{sep}` | the scheme's separator (default `-`) |

Other options per scheme: counter digits, case style (keep / Title Case / kebab-case / snake_case) and counter scope:

- **Continue numbering** (default): highest matching number in the destination + 1. Ideal if you keep one parent folder per year.
- **Restart every year:** use this if all your projects live in one folder.

Only folders that match the pattern are counted, so unrelated folders never change the number.

## Templates

- **Presets** are JSON files in `src/oneclick/builtin_templates/`.
- **Edit any template:** *Edit* next to the template dropdown (or *Settings → Templates*). Editing a preset or a folder template saves a new template of your own; presets are never changed. Your templates live in `settings.json`.
- **Your own folder:** *Use a folder as template…* in the main window, or *Settings → Templates → Add folder template…*. The folder is copied as-is (empty folders too). Ignored: `.DS_Store`, `Thumbs.db`, `desktop.ini`, `.git`, symlinks. *Duplicate* turns it into an editable template (folder structure only).
- Optionally put a `template.json` in that folder to give it a name: `{"name": "My Structure", "description": "…"}`. It is never copied.
- Limit: 2000 items / 200 MB, so pointing at a huge folder by mistake is refused.

Text files in preset manifests can use `{{project_name}}`, `{{folder_name}}`, `{{number}}`, `{{year}}`, `{{date}}`.

## Desktop shortcut

*Settings → General → Add shortcut to Desktop*, or `python run.py --desktop-shortcut`. Launches the app with the Project Starter icon and no console window (Windows `.lnk`; macOS `.command` when run from source, or a link to the `.app`).

## Right-click menu

*Settings → General → Add 'New project here'*, or `python run.py --install-context-menu` (`--uninstall-context-menu` removes it).

- **Windows:** per-user registry entries, no admin rights. On Windows 11 it appears under *Show more options*.
- **macOS:** two Finder Quick Actions in `~/Library/Services` (one for a selected folder, one for the window background). These are generated by code and **not yet verified on a Mac**. If they don't show up, enable them in *System Settings → Keyboard → Keyboard Shortcuts → Services*, or create a Quick Action in Automator that runs `/path/to/ProjectStarter.app/Contents/MacOS/ProjectStarter --dest "$1"`.

## Where things are stored

`%APPDATA%\ProjectStarter` on Windows, `~/Library/Application Support/ProjectStarter` on macOS: `settings.json`, `last_project.json` (for undo) and `oneclick.log`. Set `ONECLICK_HOME` to use another folder.

## Build the apps

```
pip install pyinstaller
pyinstaller packaging/oneclick.spec --noconfirm
```

Output goes to `dist/` (`ProjectStarter.exe` on Windows, `ProjectStarter.app` on macOS; build on each OS). GitHub Actions (`.github/workflows/build.yml`) builds both on every push and attaches them to a release when you push a tag like `v2.2.0`. See `RELEASING.md`.

The apps are **not code-signed**, so on first run:

- **macOS (Gatekeeper):** right-click the app → *Open* → *Open*, or *System Settings → Privacy & Security → Open Anyway*.
- **Windows (SmartScreen):** *More info* → *Run anyway*.

The macOS build from GitHub's `macos-latest` runner targets Apple Silicon. Intel Macs need a separate build.

## Assets

Button corner images and the embedded logo are generated by `packaging/make_assets.py` (needs Pillow): `python packaging/make_assets.py --kal Symbol-32.png --app icon32.png icon64.png icon256.png`.

## Tests

```
pip install pytest
python -m pytest
```

The core (naming, counter, templates, creation, undo, settings) and the window's logic are tested without a display. `tests/fake_tk.py` stands in for Tkinter to check the window code is wired correctly; it does not replace trying the real window.

## Layout

```
run.py                     launcher / PyInstaller entry point
src/oneclick/core/         naming, counter, sanitising, templates, create, undo, settings (no UI)
src/oneclick/system/       data folders, open folder, logging, right-click menu
src/oneclick/ui/           controller (logic), main window, settings window
src/oneclick/builtin_templates/   preset manifests
packaging/                 PyInstaller spec and icons
tests/
```
